# Intelligent Customer Churn Prediction & Customer Risk Analysis System

## Project Overview

This project is an end-to-end Machine Learning project developed during my AI/ML internship.

The main goal of this project is to predict whether a customer is likely to leave a company and classify customers into different risk levels based on their churn probability.

The project uses customer information such as monthly charges, tenure, usage, login frequency, support tickets, complaints, and customer satisfaction to identify customers who may be at risk of churning.

## Project Objective

The objectives of this project are:

- Understand and prepare customer data
- Clean missing and invalid data
- Perform Exploratory Data Analysis (EDA)
- Identify factors related to customer churn
- Perform feature engineering
- Convert categorical data into numerical form
- Train Machine Learning classification models
- Evaluate and compare different models
- Predict customer churn probability
- Classify customers into Low, Medium, and High risk
- Generate a customer risk report
- Provide business-oriented retention insights


##  Dataset

The project uses a customer dataset containing 10,000 customer records and 18 original features.

### Main Features

| Feature | Description |
|---|---| Customer_ID | Unique customer identifier |
| Age | Age of the customer |
| Gender | Gender of the customer |
| Location | Customer location |
| Tenure_Months | Number of months the customer has stayed |
| Monthly_Charges | Monthly amount paid by the customer |
| Total_Charges | Total amount paid |
| Subscription_Type | Type of subscription |
| Payment_Method | Customer payment method |
| Login_Frequency | Number of customer logins |
| Support_Tickets | Number of support tickets |
| Complaints | Number of complaints |
| Discount_Received | Whether customer received a discount |
| Contract_Type | Type of contract |
| Last_Login_Days | Days since last login |
| Usage_Hours | Customer usage hours |
| Customer_Satisfaction | Customer satisfaction score |
| Churn | Target variable |

### Target Variable

- `0` → Customer retained
- `1` → Customer churned
